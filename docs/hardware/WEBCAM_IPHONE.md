# 電腦相機與 iPhone 接續互通相機

## 需要準備的東西

- 已能開啟 EdgeLens 的電腦。
- 筆電內建相機，或 USB 相機與可傳資料的 USB 線。
- 使用 iPhone 時：Mac、支架，以及支援接續互通相機的 iPhone。此功能至少需要 iPhone XR、iOS 16 與 macOS Ventura 13；更新機型仍請核對 [Apple 系統需求](https://support.apple.com/zh-tw/102546)。

這份指南的引號表示 EdgeLens 顯示文字。系統設定與 Apple 功能名稱另行註明。

## 步驟

### A. 內建或 USB 相機

1. 內建相機請打開鏡頭遮板；USB 相機請接到電腦。
   **成功時：** 接頭穩固，鏡頭前沒有遮擋。此時指示燈不一定會亮。
2. 關閉正在使用相機的程式，例如 Teams、LINE、Zoom、Windows 相機 App。
   **成功時：** 這些程式不再顯示即時影像。接著到下方加入相機。

### B. iPhone 接續互通相機（Mac）

1. 在 Mac 與 iPhone 登入同一個 Apple ID（現在稱 Apple 帳號），並開啟雙重認證。
   **成功時：** 兩台裝置的系統設定顯示同一個帳號。
2. 開啟兩台裝置的藍牙與 Wi-Fi，放在彼此附近。先停止 iPhone 個人熱點與 Mac 網際網路共享。
   **成功時：** 藍牙與 Wi-Fi 都是開啟狀態。
3. 在 iPhone 的系統設定依序找「設定 → 一般 → AirPlay 與接續互通」（舊版可能是「AirPlay 與接力」），開啟接續互通相機。
   **成功時：** 該功能開關已開啟。
4. 將 iPhone 鎖定，穩固放在支架上，後置鏡頭朝向拍攝物；可先橫放。
   **成功時：** 手機不會滑落，鏡頭沒有被擋住。下方按「尋找」後，清單應出現手機。

這些條件依 [Apple 接續互通相機說明](https://support.apple.com/zh-tw/102546) 整理。用 USB 連接時，還要先在 iPhone 信任這台 Mac。這裡使用的是 Mac 的相機功能；Windows 或 Linux 若要用手機，請看 [網路相機指南](NETWORK_CAMERAS.md)。

## 在 EdgeLens 裡加入相機

1. 按「新增相機」，選「電腦相機（USB 或內建）」。
   **成功時：** 右側出現「尋找」與「手動輸入」。
2. 按「尋找」，等清單出現相機名稱，再點選想用的相機。
   **成功時：** 該列被選取。iPhone 旁可能顯示「iPhone 接續互通相機」；「桌上視角（Desk View）」是另一種視角。
3. 按「開啟」。
   **成功時：** 畫面開始更新；在鏡頭前移動手掌，畫面跟著變化。
4. macOS 第一次使用可能跳出系統權限視窗，請允許。若 EdgeLens 顯示錯誤，授權後按畫面上的「重試」。
   **成功時：** 錯誤消失，出現即時影像。若仍無畫面，依下方 macOS 提示處理。

**清單沒有相機時：** 可在「手動輸入」輸入「相機編號」（通常先試 `0`），「相機介面」先選「自動」，按「加入」。成功時同樣會出現即時影像。編號會因電腦與插孔改變，優先使用「尋找」找到的名稱。

**iPhone 改過名字也能辨識：** macOS 能回報型號時，EdgeLens 會用型號辨識 iPhone，不只搜尋名稱中的 iPhone 字樣。但改名後，先前儲存的名稱可能失效；請重新「尋找」並選新名稱。系統沒有提供型號時，仍可能無法顯示 iPhone 標記。

## 常見問題

以下保留程式訊息原文。`{index}`、`{name}`、`{path}` 會換成你的編號、名稱或裝置路徑。

| 畫面訊息原文 | 做什麼 | 看到什麼代表成功 |
|---|---|---|
| 打不開相機（編號 {index}）。 | 依下方作業系統提示檢查後，按「重試」。 | 出現即時影像。 |
| 相機（編號 {index}）打開了，但是一直沒有畫面。 | 打開鏡頭遮板、關閉其他相機程式；iPhone 重新鎖定並放好。 | 手掌移動時畫面有變化。 |
| 找不到名為「{name}」的相機。 | 重新插妥 USB，或在「新增相機」重新「尋找」選新名稱。 | 清單找到正確相機，能開啟。 |
| 相機的畫面中斷了，可能是 USB 線被拔掉。 | 插好 USB 線後按「重試」；iPhone 則確認仍在 Mac 附近。 | 畫面恢復。 |
| 找不到相機裝置 {path}。 | 確認相機有接好，重新尋找相機，核對編號。 | 出現正確的裝置並能開啟。 |
| 沒有權限使用相機裝置 {path}。 | 請老師協助加入 `video` 群組，登出再登入。 | 重新開啟後不再顯示權限錯誤。 |
| 請先把對應的「自動」選項關掉，手動調整才有作用。 | 先關掉對應的「自動曝光」、「自動白平衡」或「自動對焦」，再改手動值。只會出現相機支援的項目。 | 手動值改變後，畫面有相應變化。 |
| 已送出設定，但相機回報的值不一樣，可能這個值不能用。 | 改用較接近原值的設定；不要把送出成功當成硬體已套用。 | 顯示「相機已確認收到這個設定」或實際畫面符合預期。 |
| 相機不支援這個解析度，改用了最接近的解析度。 | 接受相機實際支援的大小，查看相機資訊。 | 畫面正常，顯示實際解析度。 |

macOS 提示原文：

> 第一次使用時會跳出權限視窗，請按「允許」後再按「重試」。如果沒有跳出視窗，請到 系統設定 → 隱私權與安全性 → 相機，允許「終端機」（或你用來開啟 EdgeLens 的程式），然後按「重試」。

若系統要求結束再開啟程式，請照做，再回 EdgeLens 重新開啟相機。授權對象是啟動 EdgeLens 的程式，不一定叫 EdgeLens。

Windows 提示原文：

> 相機可能正被其他程式使用（例如 Teams、LINE、Zoom、「相機」App），請把它們關掉後按「重試」。也可以到 設定 → 隱私權與安全性 → 相機，確認允許桌面應用程式使用相機。

Linux 提示原文（由老師確認系統有 `video` 群組後操作）：

> 請把自己加入 video 群組：sudo usermod -aG video $USER，然後登出再登入，之後按「重試」。（裝置：{path}）

## 進階（可略過）

### macOS 看不到亮度滑桿，是正常的

程式對 macOS 相機介面的說明原文：

> macOS 的相機介面幾乎不開放亮度、對比等參數，這是正常的；這裡只能調整解析度與每秒張數。

在「相機」面板可改「解析度」與「每秒張數」。修改會重新開啟相機，畫面短暫停住；恢復影像代表重新開啟成功。Windows／Linux 的其他滑桿也只會在探測到相機支援時出現。

### Windows 的驅動程式設定視窗

1. 先用「關閉作用中相機」關閉作用中的相機，再按「新增相機」。
   **成功時：** 原相機畫面已關閉，出現新增對話框。
2. 選「電腦相機（USB 或內建）」，在「手動輸入」把「相機介面」改成「DirectShow（Windows）」，填正確的「相機編號」，按「加入」。
   **成功時：** 相機畫面出現。不同相機介面的編號可能不同，需核對畫面。
3. 在「相機」面板按「開啟相機驅動程式設定視窗」。
   **成功時：** 開啟相機廠商提供的視窗。裡面的項目依驅動程式而定。

此按鈕只在 DirectShow 介面出現。驅動沒有提供設定視窗時，請用 EdgeLens 已顯示的參數。
