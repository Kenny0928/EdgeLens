# K210 開發板連接指南

## 需要準備的東西

- 已能開啟 EdgeLens 的電腦。
- 支援 **MaixPy v1** 的 K210 板，例如 Maix Bit、Maix Dock、Maixduino，以及相容鏡頭。
- 可以傳資料的 USB 線；只有充電功能的線不能用。
- 與板子相符的 MaixPy v1 韌體。EdgeLens 內附串流程式以 `v0.6.3_2` 為基準，其他韌體版本與感光元件仍需老師確認。
- 要跑板上模型時，另備與此韌體相容的 `.kmodel`，以及正確的模型輸入大小、類別名稱與模型說明檔。

這裡的 K210 來源透過 USB **序列埠**傳影像，不會把板子當作一般 USB webcam。MaixPy v4／其他晶片的開發板不能直接套用本指南。

## 步驟

1. 查看板子型號與 USB 轉序列晶片標示。常見 CH340／CH341、FT2232，也有 CH552 或 CP210x。
   **成功時：** 能在板子廠商文件找到相同版本。晶片種類**依你的板子而定**，不要只憑 Maix Bit／Dock 的名稱判斷。
2. 接上可傳資料的 USB 線，等電腦辨識，再依下表確認驅動。

   | 系統 | 做什麼 | 看到什麼代表成功 |
   |---|---|---|
   | Windows | 在系統的裝置管理員查看是否出現 COM 序列埠。系統可能已自動安裝；若沒有、或有警告符號，請老師依實際晶片安裝廠商驅動。 | 出現例如 `COM3` 的序列埠，沒有驅動錯誤。 |
   | macOS | 先試 EdgeLens 的「尋找」。若無序列埠，先換資料線／插孔，再由老師依 macOS 版本與晶片確認驅動；不要一開始就混裝多種驅動。 | 出現例如 `/dev/cu.usbserial-…` 或 `/dev/cu.usbmodem…`。 |
   | Linux | 通常已有 USB 序列埠驅動；權限問題見下方 `dialout` 說明。 | 出現例如 `/dev/ttyUSB0`，能正常開啟。 |

   板子版本與驅動差異見 [Sipeed Maix Bit 驅動說明](https://wiki.sipeed.com/soft/maixpy/en/get_started/install_driver/bit.html)；FT2232 請查 [FTDI 官方 VCP 驅動](https://ftdichip.com/drivers/vcp-drivers/) 的系統相容性。已能看到並開啟序列埠，就不必重裝。
3. 關閉 MaixPy IDE、Arduino 序列埠監控視窗、miniterm，以及其他正在連接同一塊板子的程式。
   **成功時：** 其他程式已中斷序列埠連線，接著交給 EdgeLens 使用。

## 在 EdgeLens 裡加入相機

1. 按「新增相機」，選「K210 開發板（Maixduino／Maix Bit）」，再按「尋找」。
   **成功時：** 清單出現序列埠與晶片資訊。
2. 選對應的板子，按「開啟」。也可在「手動輸入」把「序列埠（留空自動尋找）」留空，再按「加入」。
   **成功時：** 只有一個符合的序列埠時，EdgeLens 自動選用它。若有好幾個，請填入確認過的埠名。
3. 「連線速度（一般不用改）」先維持 `115200`。macOS 手動輸入時，使用 `/dev/cu.*` 的完整路徑。
   **成功時：** 不再出現找不到埠或沒有回應的錯誤。串流啟動後程式會自行切換到 1,500,000，不必手動改。
4. 等幾秒，先不要連續按按鈕。
   **成功時：** 鏡頭畫面出現，移動物品時影像跟著變化。第一次開啟會送出約十幾 KB 的串流程式；其實每次重新啟動串流都會送出，不是永久燒錄韌體。
5. 點選「K210 開發板」分頁，查看「板子資訊」與「板上即時數據」。
   **成功時：** 可看到「韌體」、「感光元件」與持續更新的數據。

自動尋找是依 USB 的 VID/PID（廠商與產品識別碼）挑出可能的序列埠。其他裝置也可能用相同晶片，所以「找到」不保證一定是 K210。FT2232 的雙介面裝置會優先使用第一個介面；實際接法依板子而定。

### 哪些參數會立刻生效？

在「相機」面板一次改一個值，再看畫面及回報。

| 類型 | 介面上的項目 | 成功時會看到什麼 |
|---|---|---|
| 即時修改 | 「亮度」、「對比」、「飽和度」、「自動增益」、「增益」、「自動曝光」、「曝光」、「自動白平衡」、「上下翻轉」、「左右鏡像」 | 串流繼續，板子回覆設定；實際效果依感光元件支援。手動增益／曝光要先關掉對應自動功能。 |
| 板上偵測即時修改 | 「板上偵測信心門檻」、「板上重疊框合併門檻」 | 已載入相容偵測模型時，板子重新套用門檻；沒有模型時不會憑空出現辨識結果。 |
| 重新啟動串流 | 「解析度（改了會重新啟動）」、「色彩（改了會重新啟動）」、「每幾張傳一張影像（0＝只傳數據）」、「JPEG 品質」 | 畫面停一下，之後用新設定繼續；不必重插 USB。 |

「每幾張傳一張影像（0＝只傳數據）」初學請留 `1`。設成 `0` 是只傳數據，沒有新影像，不適合用來檢查鏡頭是否正常。

## 常見問題

訊息中的 `{port}`、`{ports}`、`{seconds}`、`{detail}` 會換成實際資料。

| 訊息原文 | 做什麼 | 看到什麼代表成功 |
|---|---|---|
| 找不到 K210 開發板的 USB 序列埠。 | 換可傳資料的 USB 線，檢查驅動，再按「尋找」。 | 清單出現序列埠。 |
| 找到好幾個可能的序列埠（{ports}），請在新增相機時指定要用哪一個。 | 在「序列埠（留空自動尋找）」填明確埠名。請老師核對哪個連到 K210。 | 正確板子能開啟。 |
| 序列埠 {port} 正在被別的程式使用，所以打不開。 | 關閉 MaixPy IDE、Arduino 監控視窗及其他 EdgeLens 視窗，再按「重試」。 | 不再顯示占用，畫面出現。 |
| 找不到序列埠 {port}，可能是 USB 線被拔掉了。 | 檢查 USB 線，重新尋找埠名。 | 出現新埠名並能連接。 |
| 沒有權限使用序列埠 {port}。 | Linux 請老師依下方提示處理 `dialout` 權限。 | 重新登入後可以開啟。 |
| 板子沒有回應。 | 確認 MaixPy v1 韌體，按板子 RESET，稍等後按「重試」。 | 板子開始傳影像。 |
| 板子在 {seconds} 秒內沒有開始傳送影像。 | 不要一直按重試。先讓老師查看板子回報，確認韌體、鏡頭與模型；再 RESET。 | 在等待後出現影像。 |
| 板子很久沒有傳來資料了。 | 檢查電源與線材，按「重試」；必要時 RESET。 | 影像重新更新。 |
| 已送出設定，但板子沒有回覆，無法確認有沒有生效。 | 等一下再調整；請老師核對感光元件支援。 | 顯示「相機已確認收到這個設定」，或確認實際效果。 |
| 板子上沒有偵測到 SD 卡，無法把模型放到 /sd/。請插入 SD 卡，或改放到 /flash/。 | 先停止使用板子，再依板子說明裝好 SD 卡；或改用 `/flash/`。 | 板子偵測到卡，檔案可上傳。 |

程式的占用提示原文：

> 請關掉其他正在使用這個序列埠的程式（例如另一個 EdgeLens 視窗、終端機的 miniterm、Arduino 序列埠監控視窗），再按「重試」。

程式的 RESET 提示原文：

> 請按一下板子上的 RESET 鍵，或把 USB 線拔掉再插上，等幾秒後按「重試」。

Linux 提示原文（請老師先確認系統使用 `dialout` 群組）：

> 在終端機輸入「sudo usermod -a -G dialout $USER」，然後登出再登入一次。

正常關閉時，EdgeLens 會停止串流並釋放序列埠。可連續關閉、重新開啟，**不需要每次重插 USB**。只有異常無回應時才依提示 RESET／重插。不要同時用序列埠監控視窗看串流；那是二進位資料，顯示亂碼不代表韌體壞掉。

## 進階（可略過）

### 板上模型：由老師準備

目前板上程式支援 **YOLOv2 偵測**與**分類模型**。必須是符合 K210 與所用 MaixPy v1 韌體的 `.kmodel`；把一般 ONNX 或其他 YOLO 模型改副檔名不能使用。

- 模型放在板子 `/flash/model.kmodel`，或已掛載 SD 卡的 `/sd/model.kmodel`。
- 模型說明檔 `device.path` 要與板上路徑一致；類別名稱與數量要對應訓練結果。
- YOLOv2 要提供正確 anchors（5 組、10 個數字）。目前偵測畫面大小須符合模型輸入；分類則會縮放。
- 模型大小、kmodel 版本、記憶體與感光元件都**依你的板子與韌體而定**。請老師先核對模型轉換紀錄與韌體文件，再在實機確認。

**上傳與載入是兩件事：** 下方「K210 開發板」分頁可上傳檔案。上傳完成只代表檔案在板子裡，並不等於已載入模型。載入可由老師透過現有的 `K210Source.run_action("load_model", card=...)` 來源 API，傳入包含上述設定的 `ModelCard`。請先在實機核對模型載入成功與辨識結果，再帶學生做模型課程。

若收到下列訊息，請老師核對記憶體與韌體：

> 板子的記憶體不夠用了，可以試試較小的解析度或較小的模型。<br>{text}

> 這塊板子的韌體沒有 KPU（神經網路加速器），無法執行模型。

`{text}` 是板子回傳的補充文字。可先試較小模型或較小解析度；偵測模型仍須符合輸入大小。

### 上傳檔案到板子

1. 在「K210 開發板」分頁的「上傳檔案到板子」區按「瀏覽…」，選電腦上的檔案。
   **成功時：** 檔案路徑填入，並帶出「板上檔名」。
2. 選 `/flash/` 或 `/sd/`，核對「板上檔名」只填檔名，例如 `model.kmodel`。
   **成功時：** 目標位置與名稱正確；同名檔案會被覆蓋，先保留備份。
3. 按「上傳」，閱讀確認視窗再確認。等待畫面恢復。
   **成功時：** 顯示「已上傳到板子：{remote}」，其中 `{remote}` 是目標路徑。

### CPU／KPU 頻率

「設定 CPU／KPU 頻率」可設定頻率，再按「套用」。初學者先保留預設值。程式提示原文：

> 預設是 400／400 MHz。設定後板子會重新開機，約需十幾秒。

> 注意：超過 400 MHz 屬於超頻，板子可能發燙、當機或不穩定，請先確認散熱，若出現問題請改回 400。

請老師確認板子與散熱後再操作；數值欄允許 `100–600 MHz`，不代表每個數字都能在板上穩定運作。KPU 頻率以除頻方式設定，實際頻率未必等於輸入值，需要實機讀回確認。完成時顯示「已設定處理器速度，板子重新開機並重新連線了。」且畫面恢復。

### 燒錄韌體

**請由老師操作。** 先備份板上檔案，確認韌體確實適用板子版本。程式風險提示原文：

> 危險動作：燒錄時絕對不可以拔掉 USB 線或關掉程式！燒錄會清除板子上所有的程式與檔案。

1. 在「K210 開發板」分頁的「燒錄韌體」區按「瀏覽…」，選 `.bin`，核對「板子型號」。
   **成功時：** 顯示正確檔案與板型。預設 `maixduino` 不適用所有板子；Maix Bit／Dock 的選項需依官方燒錄文件確認。
2. 按「燒錄」，老師再次檢查確認視窗後才繼續。燒錄期間不能拔 USB、斷電或關閉 EdgeLens，也不要為了加快流程按取消。
   **成功時：** 顯示「韌體燒錄完成。」。
3. 依程式提示等待後重新連線：
   > 請等 5 秒讓板子開機，再重新開啟這台相機。

   **成功時：** 重新加入或重新開啟 K210 後，鏡頭影像恢復。

若中途取消，訊息原文是：

> 燒錄已取消。板子上的韌體可能不完整，請重新燒錄後才能使用。

這時請交給老師重新燒錄。實際覆寫範圍依映像與燒錄方式而定，準備時一律當作板上資料會遺失。

### 沒有板子也能練習連線介面

在「序列埠（留空自動尋找）」填 `sim:`，按「加入」。成功時會出現合成影像。這是 `sim.py` 的通訊模擬，不會執行真正的 MaixPy 或 KPU，也不能證明模型、驅動、鏡頭或燒錄能在實機成功。
