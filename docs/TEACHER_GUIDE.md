# EdgeLens 教師指南

EdgeLens 適合各種分類與偵測專題。相機、類別、模型與處理流程都依專案安排；剪刀石頭布與筊杯只是入門範本。初次操作請搭配[學生操作手冊](STUDENT_GUIDE.md)。

## 安裝到教室電腦

### 先驗證一台，再部署全班

1. 按[快速開始](../README.zh-TW.md#快速開始)安裝 Python 3.10–3.13、下載 ZIP 並完整解壓。Windows 勾選 **Add python.exe to PATH**。Linux 需有對應版本的 `venv` 與 `pip`。
2. 使用學生上課時的帳號開啟程式。第一次約下載 300–400 MB；預留安裝時間與照片、影片的磁碟空間。先用「測試圖案（不需相機）」完成建立專案、拍照、匯出與錄影，再測課堂實際使用的相機。
3. 確認選配套件。ONNX Runtime、TFLite 與 K210 燒錄工具的可用性依系統而異；安裝主程式成功不代表所有選配套件都成功。先用課堂的模型實測，再決定學生要裝哪些功能。
4. 將同一版解壓後程式發到其他電腦，在各台機器執行啟動器。**不要跨電腦複製 Python 虛擬環境**；使用 wheelhouse 在目標電腦建立環境。
5. 若教室電腦重新開機會還原，請與管理人員確認專案保存區、使用者快取和設定是否保留。至少做一次重新開機後再開啟、確認照片仍存在的測試。

### 離線 wheelhouse

依作業系統、CPU 架構（例如 Apple Silicon／Intel）與 Python 次版本分別準備。以下以 macOS／Linux 的 `python3` 示範；Windows 改用安裝好的 `py -3.12` 等命令。

```bash
# 在有網路的準備機器，於解壓後的 EdgeLens 資料夾執行
python3 bootstrap.py --make-wheelhouse ./wheelhouse

# 把程式與 wheelhouse 一起複製到離線電腦，再於該資料夾執行
python3 bootstrap.py --wheelhouse ./wheelhouse
```

兩個參數都要帶資料夾路徑。`--make-wheelhouse` 下載必要與選配套件；某個選配下載失敗可能被略過，請保留訊息並檢查。離線安裝的套件來源使用本機 wheelhouse；如果缺輪檔，回相同平台的連網機器重新準備。用目標電腦的學生帳號做一次完整離線啟動驗證。

Python 安裝程式、相機驅動、模型及其類別檔、K210 韌體不包含在 wheelhouse 內，需另行準備。正式上課前把範例影片、模型和專案都放在本機。

### 學校網路與雲端同步

- 套件安裝失敗時，請網管檢查 PyPI 及套件下載站的連線、代理伺服器與憑證設定，或改用 wheelhouse。不要以關閉憑證驗證來解決。
- 同一個 Wi-Fi 名稱不保證電腦能連到 ESP32-CAM 或 IP camera；教室網路可能隔離用戶端。先確認相機網址能從教室電腦存取，再加入 EdgeLens。網路相機的電源、IP、埠號與帳密應由老師管理。
- **工作區不要放在 iCloud／OneDrive／Dropbox／Google Drive 等同步資料夾。** 系統預設的文件或桌面也可能正在同步。雲端佔位檔、同步延遲或衝突可能讓照片無法讀取。請選確定在本機、可寫入的資料夾。
- 啟動器將環境放在本機快取；專案資料則在工作區，兩者不同。備份時先結束 EdgeLens，再複製整個專案；若要上傳雲端，另製作備份 ZIP，而不是直接在同步資料夾裡工作。

## 工作區與專案怎麼規劃

每台電腦可有一個工作區，每班或每組建立一個專案，例如 `801_group03_leaves`。多人同時操作時，每台電腦各用本機副本，指定一人彙整；不要讓多個程式同時寫同一份資料集。

```text
工作區/
  plugins/                    此工作區共用的 Python 外掛
  projects/
    801_group03_leaves/
      project.json            名稱、類別、顏色、快捷鍵
      dataset/                原始／處理照片、metadata.jsonl、切分資料
      models/                 模型、類別名稱、模型說明檔
      pipelines/              已另存的處理流程
      references/             構圖參考照片
      recordings/             影片及相關 CSV
      logs/                   效能紀錄
      exports/                匯出的資料集 ZIP
```

用「檔案」→「在檔案總管中開啟專案資料夾」找到目前專案。發給學生或收作業時，先停止拍照、錄影並結束程式，再**整個複製專案資料夾**到另一個工作區的 `projects/` 下；避免覆蓋同名資料夾。重新開啟程式後，透過「開啟專案…」選擇。收回不同組時保留不同資料夾名稱，勿直接合併各組 `metadata.jsonl`。

專案不是整台電腦設定的備份。相機連線設定與目前作用中的處理流程在本機設定中；要交接流程，請在「影像處理」按「另存為預設」，接收者再套用專案預設。參考照片會跟專案複製，但接收者可能要重新選擇。外掛在工作區的 `plugins/`，需要另外附上。模型及相關檔案請放 `models/` 並使用可搬移的相對路徑；指向外部絕對路徑的檔案不會自動被複製。

建立類別前先訂清楚判斷規則，例如哪些情況屬於背景、遮擋或沒有目標。類別 `ID` 是檔案識別碼，中文顯示名稱可調整。課堂中不要直接改類別資料夾名稱；整理照片用資料集瀏覽器，保留中繼資料一致。

## 建議教學流程：六節課

| 節次 | 學習重點 | 學生產出與教師觀察 |
|---|---|---|
| 1 | 認識相機、像素、解析度與亮度；先用模擬來源再接真相機 | 能說明畫面變化，知道 ✓／?／✗ 的差異，建立專案與類別規則 |
| 2 | 灰階、濾波、二值化、顏色遮罩；改變步驟順序 | 保存一組處理預設，附原始與處理後畫面的比較及理由 |
| 3 | 蒐集樣本、品質檢查、類別平衡、清理相似照片 | 每類有足夠變化；提供張數表、失敗樣本與清理理由 |
| 4 | 切分資料，匯出到外部平台訓練 | 保存亂數種子、切分張數、訓練設定；保留未用於調整的測試資料 |
| 5 | 將訓練完成的模型帶回 EdgeLens 測試 | 記錄模型版本、輸入條件與錯誤案例；格式準備見模型支援文件 |
| 6 | 比較相機、模型或影像處理設定，提出改進 | 每次只改一個主要變因，繳交數據、錄影與結論；用新樣本驗證改進 |

四節課可合併第 1–2 節與第 5–6 節；安裝、模型準備與部分訓練等待由老師課前完成。訓練使用 Teachable Machine、Edge Impulse、Keras 或 MaixHub 等外部工具。EdgeLens 的資料夾匯出是分類照片，不含人工偵測框；偵測專題需增加標註課程。

### 模型面板

- 第 5 節課前，老師先用自己的電腦載入每組的模型確認能跑：看「模型資訊」的「任務」與「類別」是否正確、框的位置是否對。格式判斷有疑義時（出現「請確認輸出格式」），選好正確的格式後按「另存模型說明檔…」，把 `.card.json` 和模型一起發給學生，學生就不用再判斷。格式與範例說明檔見[模型支援說明](MODEL_SUPPORT.md)。
- 沒有自己的模型時，「OpenCV 內附偵測器」（正臉、側臉、眼睛、上半身、貓臉等）可以先拿來介紹「偵測」與「信心門檻」的概念。
- 「保留目前的模型，再加一個模型做 A/B 比較」可讓學生在同一個畫面比較兩個版本的模型（例如資料增加前後）。
- K210 的 `.kmodel` 只能在板上執行，要先開啟 K210 相機；板上只支援 YOLOv2 與分類模型。
- 學生拍照時若有模型在跑，照片紀錄會包含當時的辨識結果，可用來挑出模型認錯的樣本，當作下一輪蒐集資料的方向。

### 比較面板

- 適合第 6 節課的對照實驗：例如同一個模型在電腦相機、ESP32-CAM、K210 上的表現，或同一台相機上兩個模型的速度與偵測率。
- 提醒學生每次只改一個變因；換設定後按「全部重設統計」，觀察固定時間（例如 1 分鐘）再「匯出比較表 CSV」。
- 「偵測率」是最近約 10 秒內有偵測到東西的畫面比例，適合比較「穩不穩定」；要比較「準不準」，請用資料集與測試照片另外評估。

## 評量建議

| 面向 | 建議比重 | 可檢查的證據 |
|---|---|---|
| 資料集品質 | 30% | 標籤是否一致；是否涵蓋不同背景、光線、角度；能否說明保留與刪除原因 |
| 類別平衡與切分 | 25% | 每類張數、切分紀錄；同一物品／同次連拍是否洩漏到測試集；少數類別如何補足 |
| 比較實驗 | 30% | 固定測試資料與場景，記錄相機、解析度、模型與前處理；同時看正確性、FPS 和延遲 |
| 解釋與改進 | 15% | 至少分析幾個誤判案例；提出可檢驗的改進，再用保留的資料確認 |

不要只評最高準確率或照片總量。同一場連拍、同一背景拍很多張，未必代表多樣性。EdgeLens 會保留連拍與多相機分組，但不同時間另拍的同一物品仍需師生自行檢查資料洩漏。小資料集分組後，某類可能在驗證或測試份數太少，需補拍獨立場景。

比較速度時，記下測試電腦、相機、解析度、處理步驟、測試秒數、模型版本與輸入大小；板上推論和電腦端推論要分別說明。若畫面或辨識錯誤，就算 FPS 高也不能判定整體較好。

## 常見問題與診斷 ZIP

| 問題 | 建議檢查 |
|---|---|
| 雙擊後無法啟動 | Python 是否為 3.10–3.13、Windows PATH、是否完整解壓、macOS 隔離屬性／執行權限、Linux venv／pip |
| 離線環境缺套件 | wheelhouse 是否對應 OS、架構和 Python 次版本；是否有選配下載失敗；先保留啟動訊息 |
| 找不到相機／沒有畫面 | 先用測試圖案分離程式與硬體問題；查系統權限、其他程式占用、線材或網路；依各硬體指南處理 |
| 參數顯示 ? 或 ✗ | ? 表示無法讀回確認，✗ 表示不接受或操作失敗；某些手動設定受自動曝光／白平衡限制 |
| 不能拍照或張數不足 | 確認專案、類別、相機畫面及品質檢查；在文字欄中按空白鍵不會拍照；等待存檔完成 |
| 照片突然不見、匯出失敗 | 查同步資料夾、磁碟空間、寫入權限、已刪除照片，以及照片是否屬於已移除的類別 |
| 模型不能載入 | 核對格式、執行環境、模型說明檔、類別與輸入規格；見[模型支援說明](MODEL_SUPPORT.md) |
| 外掛載入失敗 | 在診斷報告的匯入失敗清單看檔名與原因；移開問題外掛再重開；見[外掛教學](PLUGINS.md) |

請學生到「說明」→「診斷資訊…」，等收集完成後按「匯出成 ZIP…」。搭配發生時間、重現步驟、預期和實際結果一起交回。可查看「完整報告」、「自我檢查」、「設定（已隱藏密碼）」及「最近的日誌」。程式會遮蔽部分密碼資訊，但路徑、裝置名稱及日誌仍可能辨識使用者；由老師收件檢查，不要直接公開上傳。

主視窗打不開時，保留啟動器錯誤輸出。懷疑是外掛或上次相機設定時，可在程式資料夾執行 `python3 bootstrap.py --safe-mode`（Windows 改用對應的 `py`），略過外掛與自動開相機，再收集診斷。離線首次安裝需同時加上 `--wheelhouse ./wheelhouse`。

## 硬體與拍攝安全

- **K210 燒錄由老師操作。** 核對板型與韌體，先備份板上程式和檔案，視為可能全部遺失。燒錄中不可拔 USB、斷電或關閉程式。上傳同名檔案也可能覆蓋既有內容。初學保留預設 CPU／KPU 頻率；詳見 [K210 指南](hardware/K210.md)。
- **ESP32-CAM 依板子額定值供電。** 核對針腳、電源和線材後才通電，不讓學生猜接法。反覆重啟或 brownout 時先檢查供電，不要反覆換韌體碰運氣。詳見 [ESP32-CAM 指南](hardware/ESP32CAM.md)。
- 拍攝使用自己製作、取得同意或合適授權的素材。課堂樣本盡量避免學生臉部、姓名、座號與私人環境；上傳外部訓練平台前由老師確認。

## 隱私

EdgeLens 不會把照片、資料集或使用紀錄傳到網路上；資料都留在工作區與這台電腦的設定資料夾。模型推論用的 ONNX Runtime 在新版會預設開啟微軟的使用統計上傳，EdgeLens 啟動時已把它關閉。相機的網路密碼不會存進設定檔，「診斷資訊」匯出的 ZIP 也會去掉密碼。只有在安裝套件、下載測試模型，或連線到你自己設定的網路相機時才會使用網路。

## 讓學生寫外掛

完成基礎操作後，讀[外掛教學](PLUGINS.md)。先改負片公式，再看亮點比例與馬賽克參數。評量可要求：解釋輸入與輸出、不修改輸入影像、彩色與灰階都能跑、參數能存回 JSON，並用模擬圖案示範。

學生先在自己的本機工作區測試，老師讀過程式後再發給全班。外掛是完整權限的 Python 程式，不是安全沙盒；只放自己看得懂、來源可信的檔案。共用的 `kind` 要避免撞名，改完外掛請重開程式。
