# EdgeLens 學生操作手冊

先用模擬畫面練習。熟悉後，再和老師一起接真正的相機。這份手冊使用繁體中文介面；「」內是介面文字。類別名稱、張數與檔案路徑會依你的專案改變。

## 1. 打開 EdgeLens

1. 依[快速開始](../README.zh-TW.md#快速開始)裝好 Python、解壓縮程式，雙擊對應的啟動檔。第一次下載套件時不要關閉視窗。**成功時：** 出現 EdgeLens 視窗。
2. 第一次在「工作區」選老師指定的本機資料夾，按「確定」。不要選雲端同步資料夾。**成功時：** 主視窗出現，工具列可看到目前專案。
3. 若介面不是中文，用「語言」→「繁體中文」切換。**成功時：** 可看到「新增相機」等文字。

工作區像書包，裡面可以放很多專案。專案像一本專題筆記，保存類別、照片、模型和實驗紀錄。

## 2. 選或建立專案

第一次沒有專案時，程式會先建立「我的第一個專案」。你可以沿用，也可以另開新專案。

1. 已有專案：從工具列「專案」選老師指定的專案，或到「檔案」→「開啟專案…」的「選擇專案」，選好後按「確定」。**成功時：** 工具列顯示正確專案名稱。
2. 建立專案：到「檔案」→「新專案…」，在「新增專案」填「專案名稱」，例如 801_第3組_葉片分類。**成功時：** 名稱欄有你輸入的名字。
3. 在「從範本建立」選一個範本，再按「建立專案」。**成功時：** 視窗切到「類別」，可檢查或新增類別；按「確定」後才回到主視窗使用新專案。

   | 範本 | 用途 |
   |---|---|
   | 「空白專案」 | 自訂任何主題，接著自己加類別 |
   | 「範例：剪刀石頭布」 | 內建手勢與沒有手的類別 |
   | 「範例：筊杯辨識」 | 內建不同筊杯狀態與沒有筊杯的類別 |

4. 到「檔案」→「專案設定」→「類別」，用「新增」加類別，填「中文名稱」，確認「快捷鍵」，按「確定」。**成功時：** 「拍照」面板出現類別按鈕。

類別是你想分辨的答案，例如不同葉片種類。`ID` 是照片資料夾的識別名稱，建立後不要手動改。刪除類別定義不會刪掉原本的照片。範本只是起點，不限制你的研究主題。

## 3. 新增相機

1. 按「新增相機」，在左邊選「測試圖案（不需相機）」。**成功時：** 右邊出現這種來源的說明。
2. 按「尋找」，選一筆結果，再按「開啟」。**成功時：** 主視窗出現移動圖案。
3. 想練習網路相機參數，再按「新增相機」，選「模擬 ESP32-CAM（不需要硬體）」，按「尋找」，選第一筆結果後按「開啟」。**成功時：** 出現另一個移動方塊畫面，不需要接板子或填學校的 IP。
4. 點想操作的相機畫面，讓它成為作用中的相機。有多台時可用「檢視」→「2×2 並排」。**成功時：** 「相機」面板的「名稱」對應你選的來源。

真正的相機請依老師指示接線，再讀 [Webcam／iPhone](hardware/WEBCAM_IPHONE.md)、[ESP32-CAM](hardware/ESP32CAM.md)、[K210](hardware/K210.md) 或[網路相機](hardware/NETWORK_CAMERAS.md)。

## 4. 調整相機參數

1. 選作用中的相機，打開「相機」面板。**成功時：** 看到這台相機支援的參數；不同相機的項目可能不同。
2. 先只改「亮度」一個值，等畫面更新。**成功時：** 畫面亮暗改變；旁邊的符號說明相機是否確認設定。

   | 符號 | 介面說明 | 你該怎麼做 |
   |---|---|---|
   | ✓ | 「相機已確認收到這個設定」 | 可以繼續觀察效果 |
   | ? | 「無法確認相機是否真的套用」 | 指令可能已送出，但不能確定；看實際畫面 |
   | ✗ | 「相機不接受這個設定」 | 改回支援的值，讀提示或請老師協助 |

3. 改「解析度」時先等候，不要連續點。**成功時：** 畫面恢復，大小或細節改變。有些相機需要重新啟動串流。
4. 想重新練習，按「重設為預設值」。**成功時：** 參數回到預設設定，再確認畫面正常。

## 5. 影像處理

### 加入步驟與預設組合

1. 開「影像處理」，按「新增步驟」，選一個分類中的步驟。**成功時：** 步驟出現在清單裡。
2. 點該步驟，在「步驟參數」調整數值。勾選「畫面顯示處理後的影像（取消勾選就看原始畫面）」。**成功時：** 畫面隨參數改變。
3. 用「上移」或「下移」改順序，或取消步驟前面的勾選。**成功時：** 清單順序或啟用狀態改變。處理會由上到下執行，順序不同可能得到不同結果。
4. 想試現成流程，在「預設組合」選一組，再按「套用」。**成功時：** 整份步驟清單換成該組設定。想保留原流程，先按「另存為預設」取名保存。
5. 按「另存為預設」，輸入容易理解的名稱。**成功時：** 預設選單可找到新流程，檔案保存在目前專案的 `pipelines/`。

### 吸管取色

1. 在「吸管取色」按「取色」，到畫面點選目標顏色。可在目標的亮處、暗處多點幾次。**成功時：** 顯示取樣點數與顏色範圍。取樣使用原始畫面。
2. 按「套用到 HSV 遮罩」。**成功時：** 流程加入或更新 HSV 遮罩，符合顏色的區域被保留下來。需要時調「取樣半徑」與「範圍留邊」。
3. 按「複製 OpenCV HSV 範圍」或「複製 MaixPy LAB 門檻」，貼到老師指定的筆記或程式。**成功時：** 貼上得到門檻資料。兩種門檻屬於不同色彩系統，不能混用。
4. 取到背景顏色時，按「清除」重新取色。**成功時：** 取樣重新開始。

## 6. 拍照蒐集樣本

### 第一張照片

1. 開「拍照」，按正確的類別按鈕。**成功時：** 拍照按鈕顯示目前類別。類別按鈕只選答案，不會立刻拍照。
2. 看「拍照品質」，把物品放清楚、避免太暗或反光。可勾「品質太差時不要拍照」。**成功時：** 品質檢查通過；若被擋下，先依原因改善再拍。
3. 按空白鍵，或按帶有目前類別名稱的拍照按鈕。**成功時：** 出現已存檔提示，類別張數增加。數字鍵 1–9 依專案的「快捷鍵」切換類別，切換後仍要按空白鍵才拍。
4. 移動物品、更換距離或背景，再拍下一張。**成功時：** 得到不同情況的照片。若看到「這張和剛剛那張很像，換個角度或位置吧。」，照片仍可能已存下，這是提醒，不會自動刪除。

游標在文字欄或數值欄時，拍照快捷鍵不會生效；先點回畫面。是否成功以存檔提示與實際張數為準。勾選「同時另存處理後的影像」可另存處理結果，原始照片仍保留。

### 連拍、倒數與自動拍

| 做什麼 | 看到什麼代表成功 |
|---|---|
| 在「連拍、定時、自動拍」設定「連拍張數」、「連拍間隔」，按「開始連拍」 | 顯示進度；等存檔完成後檢查張數。品質檢查可能擋下部分照片，因此連拍次數不等於實際存檔數 |
| 設「倒數秒數」，按「倒數後拍照」，在倒數時擺好物品 | 畫面有倒數，歸零後出現存檔提示 |
| 勾「畫面靜止時自動拍」，設定「靜止門檻（越小越嚴格）」與「需連續靜止幾張畫面」 | 物品不動一段時間後自動存一張；拍完要先動過、再靜止，才拍下一張 |

連拍與倒數進行時，同一個按鈕會變成可取消的按鈕。不需要自動拍時，把「畫面靜止時自動拍」取消勾選。

### 構圖、多相機與類別平衡

1. 在「構圖參考」按「選擇參考照片…」，選一張清楚照片，勾「在畫面上顯示參考照片」，調「透明度」。**成功時：** 參考照片半透明疊在畫面，方便對齊物品；它不會變成原始樣本的一部分。
2. 至少兩台相機有畫面時，選好類別，按「全部相機一起拍」。**成功時：** 各相機的可用畫面分別存下，照片有共同分組。這不是硬體同步快門，拍攝瞬間可能不同。
3. 看「各類別張數」，優先補拍比較少的類別。**成功時：** 各類數量接近，而且每類都有不同角度、光線與背景。

測試圖案適合學操作；正式資料集請換成專題真正要辨識的物品。不要用大量幾乎一樣的連拍湊張數。

## 7. 整理資料集

1. 在「資料集」按「開啟資料集瀏覽器」，點照片。**成功時：** 看到大圖及拍攝資訊。
2. 用「相機」、「品質」、「連拍組」篩選，或用「排序」找清晰度較低的照片。**成功時：** 清單與顯示張數改變。
3. 選錯類別的照片，按「改成類別…」，選正確類別。**成功時：** 照片歸到新類別，張數更新。
4. 選不適合的照片，按「刪除」。想還原時，到左邊顯示已刪除張數的項目，選照片按「復原」。**成功時：** 照片先離開一般清單，再能回到原類別；這裡的刪除是可復原的。
5. 按「找相似照片」，依結果檢查重複畫面。**成功時：** 相似照片排在一起供你挑選。相似不代表一定要刪，先看是否保留了有用變化。
6. 如果老師另外放入照片到 `dataset/<class_id>/`，回「資料集」按「重新整理」。**成功時：** 新照片被納入統計。不要自行改 `metadata.jsonl`。

## 8. 切分與匯出

訓練資料用來練習，驗證資料用來調整，測試資料留到最後檢查。不要把同一張或幾乎相同的照片同時放進練習與考試。

1. 在「資料集」按「切分與匯出…」。**成功時：** 開啟「切分與匯出」視窗。
2. 設定「比例 train / val / test」，例如 70／15／15，合計必須是 100。記下「亂數種子」，按「切分」。**成功時：** 表格出現各類的實際切分張數。同一組連拍或多相機分組會留在同一份，實際比例可能略有差異。
3. 依訓練方式選格式。**成功時：** 選取下表對應的格式。

   | 要交給誰 | 格式 | 解壓後怎麼用 |
   |---|---|---|
   | Teachable Machine、Edge Impulse | 「每類一個資料夾」 | 每個類別資料夾分別提供照片；這種格式不保留 train／val／test 的資料夾分層 |
   | Keras、MaixHub | 「train／val／test 資料夾」 | 交給老師的訓練程式或平台匯入流程，保留切分 |

4. 依老師要求選「附上 labels.txt」、「附上 metadata.jsonl」與「縮圖最大邊長」。需要另外的處理結果才勾「包含處理後影像」。**成功時：** 匯出選項與老師要求相同；避免把原圖和處理圖誤當兩份獨立樣本。
5. 按「開始匯出」，等完成，再按「在檔案總管中顯示 ZIP」。**成功時：** 能在目前專案的 `exports/` 找到 ZIP，解壓後看到照片與類別資料夾。

這是分類照片資料集，沒有替物件畫偵測框。若要訓練偵測模型，還要到合適的工具標註。外部平台的匯入規則可能不同，請使用老師驗證過的流程；不是把 ZIP 丟進任何平台就能直接訓練。

## 9. 模型測試

訓練好的模型（老師給你的，或你在外部平台訓練後匯出的）可以放進 EdgeLens，看它在真的相機畫面上表現如何。

1. 選一台有畫面的相機，開「模型」。**成功時：** 看到「載入模型…」、「OpenCV 內附偵測器」、「最近用過」三個按鈕。沒有相機時會提示先新增相機。
2. 第一次練習可以按「OpenCV 內附偵測器」，選「正臉（alt2）」，不用自己準備模型。**成功時：** 鏡頭對著臉時，畫面上出現框。
3. 要用自己的模型就按「載入模型…」，選模型檔（`.onnx`、`.tflite`、Darknet 的 `.weights`、`.card.json` 等）。**成功時：** 下方顯示「「模型名稱」載入完成」，「模型資訊」列出「任務」（偵測或分類）、「輸入規格」、「類別」與「輸出格式」。
4. 看畫面：偵測模型會畫框並寫類別和分數；分類模型會在畫面底部寫出最可能的類別。「即時結果」會顯示每秒推論幾張、每張花多少時間，以及「結果是幾張以前的」。
5. 調「推論」裡的滑桿：
   - 「信心門檻」：分數低於這個值的結果不顯示。調高比較少誤判，調低比較不會漏掉。
   - 「重疊門檻（NMS）」：同一個物體被框好幾次時，只留分數最高的。
   - 「最多幾個框」：一張畫面最多顯示幾個結果。
   **成功時：** 拖動滑桿，畫面上的框馬上跟著變多或變少。
6. 如果出現「請確認輸出格式」，代表程式不太確定這個模型的格式。從下拉選單換一個選項，看哪一個的框位置正確；選對後按「另存模型說明檔…」，下次載入就不用再選。
7. 想比較兩個模型：勾「保留目前的模型，再加一個模型做 A/B 比較」，再載入第二個模型。**成功時：** 第二個模型的框是虛線、顏色不同。
8. 用完按「停止推論」。

**K210 開發板：** `.kmodel` 只能在 K210 板上執行。先開啟 K210 相機並選取它，再載入 `.kmodel`，程式會把模型傳到開發板（會顯示「正在把「名稱」傳到開發板…」）。板上算出來的框是虛線。

**拍照時會一起記錄推論結果：** 模型開著的時候拍照，照片的紀錄裡會存下當時的辨識結果，之後可以拿來找「模型認錯」的照片。

模型格式與檔案準備見[模型支援說明](MODEL_SUPPORT.md)。

## 10. 比較相機與模型

想知道「哪台相機比較適合」或「哪個模型比較好」，用「比較」面板把數字放在一起看。

1. 開兩台以上的相機（或同一台相機載入兩個模型），開「比較」，可按「切換成 2×2 並排」同時看畫面。**成功時：** 表格每一欄是一組「相機＋模型」，每一列是一個數字。
2. 看懂每一列：

   | 列 | 意思 |
   |---|---|
   | 相機 FPS | 相機每秒送來幾張畫面，越高越流暢 |
   | 延遲 | 從拍到畫面到處理完花多久，越小越即時 |
   | 推論 FPS／推論耗時 | 模型每秒能算幾張、每張花多久 |
   | 清晰度／亮度 | 畫面清不清楚、亮不亮（數字越大越清楚／越亮） |
   | 最高分數（類別） | 模型最有把握的結果 |
   | 偵測率 | 最近一段時間裡，有偵測到東西的畫面佔多少比例 |

3. **公平比較：** 讓所有相機拍同一個場景、同樣的光線；換了模型或相機之後，先按「全部重設統計」再開始計時。
4. 按「匯出比較表 CSV」把結果存起來（存在專案的 `logs/` 資料夾，可以用 Excel 開），寫進實驗紀錄。

## 11. 效能測試與錄影

1. 選一台有畫面的相機，開「效能／錄影」。**成功時：** 「FPS（每秒張數）」、「延遲（從拍攝到處理完）」與「處理耗時」持續更新。FPS 越高通常越流暢，延遲越小通常越即時。
2. 按「開始記錄數據」，觀察一段時間，再按「停止記錄數據」。**成功時：** 顯示存檔位置；按「開啟數據資料夾」可找到 CSV。
3. 在「長時間測試」設定「測試秒數」，按「開始測試」。**成功時：** 出現進度，完成後有摘要檔路徑。比較實驗要用相同秒數、光線與解析度。
4. 老師指定參數實驗時，在「參數掃描」選「要掃描的參數」，依類型設定範圍或選項，再按「開始掃描」。**成功時：** 逐個值出現結果，完成後回復原設定。真相機可能拒絕某些設定，請檢查回報。
5. 選「原始畫面」、「處理後的畫面」或「含標註（框與文字）」，按「開始錄影」。**成功時：** 顯示錄影時間和寫入張數。
6. 按「停止錄影」，再按「開啟錄影資料夾」。**成功時：** 找到影片及相關 CSV；試播確認內容。磁碟滿了或寫入失敗時，先讀錯誤提示，不要直接關機。

## 12. 出問題時

1. 沒畫面時，先確認選對相機。真相機連不上，可先用「測試圖案（不需相機）」檢查程式；依老師指示處理接線或權限後，用「相機」→「重試連線」。**成功時：** 有新畫面持續更新。
2. 問題還在，到「說明」→「診斷資訊…」，等收集完成。**成功時：** 「完整報告」、「自我檢查」與「最近的日誌」有內容。
3. 按「匯出成 ZIP…」，選可存檔的位置。**成功時：** 顯示匯出路徑，資料夾裡有 ZIP。
4. 把 ZIP 交給老師，附上發生時間、相機種類、剛做的步驟與畫面訊息。**成功時：** 老師可以知道如何重現。診斷檔可能含電腦路徑與裝置資訊，不要公開貼到網路。

若連主視窗都打不開，保留啟動視窗的錯誤文字交給老師，不必為了匯出 ZIP 一直重開。不要自行燒錄板子。
