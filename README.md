# EdgeLens

A cross-platform edge-vision camera tool for teaching: connect a webcam, iPhone, ESP32-CAM, K210 or RTSP camera,
apply image processing, run models (ONNX, TFLite, OpenCV DNN, Haar, K210 kmodel), and collect labelled photo
samples for training.
